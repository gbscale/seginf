# Firewall Linux, Arquitetura Netfilter & Iptables

Projeto desenvolvido para a disciplina de **Segurança da Informação** do **IF Goiano - Campus Ceres**.
**Docente:** Prof. Roitier Campos Gonçalves

## Descrição do Projeto
Simulação de um ambiente de rede segmentado contendo uma Rede Cliente (Intranet), um Container Firewall roteador com `iptables` (política padrão `DROP`) e uma Zona Desmilitarizada (DMZ) com serviços web e de banco de dados isolados, orquestrados via Docker Compose.

## Pré-requisitos
- Docker
- Docker Compose
